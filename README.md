# Album Studio

Генератор печатных фотоальбомов, который целиком работает в браузере.

Вы указываете папку с фотографиями — страница читает их локально, отбирает кадры
и собирает книгу минимум на 24 страницы: обложка, вступление, развороты по годам,
страница пожеланий, финал. Дальше альбом правится вручную и выгружается в PDF
300 dpi с вылетами под типографию.

**Ни один снимок не покидает компьютер.** Файлов нет на сервере: страница статическая,
всё собирается в самой вкладке.

## Что внутри

- Чтение папки целиком (`webkitdirectory`), дата съёмки из EXIF, а если её нет — из имени файла.
- Отсев дублей перцептивным хешем (dHash 8×8, расстояние Хэмминга ≤ 4).
- Оценка кадра: резкость (модуль лапласиана), контраст, доля пересветов и провалов.
- Опционально — поиск главного героя по приложенному портрету
  ([@vladmandic/face-api](https://github.com/vladmandic/face-api), модели тянутся с jsDelivr).
- Четыре оформления, пять раскладок страницы, кадрирование перетаскиванием.
- Режим просмотра разворотами.
- Генерация текстов вступления и пожеланий через Anthropic или OpenAI API —
  ключ вводится в самой странице и хранится только в `localStorage` этого браузера.
- Экспорт PDF: каждая страница рендерится в canvas на 300 dpi и вшивается в PDF
  без внешних библиотек.

## Запуск локально

Просто откройте `index.html` в Chrome или Edge. Сборки нет, зависимостей нет.

## Публикация

Репозиторий развёрнут через GitHub Pages из ветки `main`, папка `/` (корень).
Настройки: Settings → Pages → Source: Deploy from a branch → main / (root).

### Свой домен

1. В DNS домена добавьте запись:
   - для поддомена (`album.example.com`) — `CNAME` на `dburlaku.github.io`;
   - для корневого домена — четыре `A`-записи на `185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153`.
2. Settings → Pages → Custom domain — впишите домен, включите Enforce HTTPS.
3. GitHub сам создаст файл `CNAME` в репозитории.

## Форматы печати

| Формат | Обрезной | С вылетами |
|---|---|---|
| Квадрат | 210 × 210 мм | 216 × 216 мм |
| A4 альбомный | 297 × 210 мм | 303 × 216 мм |
| A5 альбомный | 210 × 148 мм | 216 × 154 мм |

Вылет 3 мм со всех сторон, фотографии «на вылет» уходят под обрез.

## Ограничения

- HEIC с айфона браузер не декодирует — такие файлы пропускаются.
- Распознавание лиц требует загрузки модели (~6 МБ) с CDN при первом использовании.
- Большие папки (сотни снимков) читаются минуты и занимают память вкладки.
